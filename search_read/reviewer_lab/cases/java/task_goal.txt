Hãy thiết kế và mã hóa từ đầu (Greenfield) một Hệ thống Đặt hàng Event-Driven (Order Processing System) bằng Java Pure gồm ĐÚNG 11 FILES.

CẤU TRÚC CODEBASE THƯ MỤC (ĐÚNG 11 FILES):
1. `src/model/OrderStatus.java` (Enum: PENDING, PAID, CANCELLED)
2. `src/model/Order.java` (POJO chứa orderId, amount, OrderStatus)
3. `src/event/OrderEvent.java` (POJO chứa eventId, Order, timestamp)
4. `src/exception/EventProcessingException.java` (Custom Exception)
5. `src/listener/IOrderEventListener.java` (Interface định nghĩa: void onEvent(OrderEvent event) throws EventProcessingException)
6. `src/listener/PaymentListener.java` (Class triển khai IOrderEventListener: cập nhật OrderStatus sang PAID)
7. `src/listener/NotificationListener.java` (Class triển khai IOrderEventListener: in thông báo gửi email)
8. `src/listener/AuditLogListener.java` (Class triển khai IOrderEventListener: ghi log lịch sử sự kiện)
9. `src/bus/EventBus.java` (Class quản lý: registerListener, unregisterListener, publishEvent)
10. `src/service/OrderService.java` (Class quản lý nghiệp vụ: chứa EventBus, method createOrder, processOrder)
11. `src/Main.java` (Class entrypoint: đăng ký 3 listeners vào EventBus, tạo order hợp lệ, kích hoạt event xử lý thành công và catch EventProcessingException khi amount <= 0)

RÀNG BUỘC KỸ THUẬT:
- Dùng package chuẩn (`model`, `event`, `exception`, `listener`, `bus`, `service`).
- Biên dịch bằng Pure JDK (`javac -d bin src/**/*.java`) và chạy `java -cp bin Main` thành công 100%.
